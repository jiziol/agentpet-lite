# AgentPet Lite：能力演进与验证边界

AgentPet Lite 基于 [ntd4996/agentpet](https://github.com/ntd4996/agentpet) 维护。以下描述当前能力和维护取舍，不将内部构建号当作公开版本，也不把本地维护中已有的能力全部宣称为 Lite 首创。源码职责见[架构指南](architecture.md)。

## 能力与边界

| 方向 | 当前实现 | 使用及维护边界 |
| --- | --- | --- |
| 桌面显示 | 宠物、多会话任务气泡、公开回复、提醒、番茄钟 | 不额外请求模型生成回复；内容可能出现在共享屏幕中 |
| 养成与动画 | 本地养成、位置、项目绑定、自定义短句、九组动画及导入 | 默认媒体的许可独立于源码 MIT；旧用户数据保留 |
| 接入管理 | Codex／agy／OpenCode／Pi 的 Install／Remove、所有权核对与隔离 Test | 不代替原生信任、登录或真实业务验收；不修改其他插件 |
| OpenCode | V1／V2 独立模板，按版本选择 | 跨主版本重新安装；V2 ≥2.2.2 支持 TUI 导航入口（2.2.2 隔离验证；需已加载 TUI part 与可定位终端） |
| Pi | 原生扩展与生命周期收尾、取消及错误区分 | 通用接入维护；AionUI 专用适配停止维护 |
| DSH | 独立 bridge 的协议消费、健康／关联／导航 | 桥由 DSH 管理侧独立维护和发行，应用不内附、构建、安装或升级桥 |
| AO 项目聚合 | 同项目一个汇总气泡，leader 主入口、独立未读成员入口、精确已读同步 | 当前验收基于官方 v0.14.6 的补丁版；新增导航／阅读接口不在官方原版中，TUI／远程／Cloud 不据此支持 |
| Codex 辅助任务 | 按精确原生来源排除内部辅助请求与临时侧边会话 | 正式主会话与真实子任务保留，不按标题或模型名粗略隐藏 |
| 产品收口 | macOS 维护版，移除旧网页同步、历史页及无效更新入口 | 底层兼容数据保留；当前无自动更新渠道 |
| 开源准备 | 明确文件允许清单，分离私人材料和公共文档 | 文件范围、内容隐私、素材许可、历史及实际构建分别审核 |

Claude Code 保留兼容入口，不承担新增适配和专项维护。AionUI／AionUI Team 的旧关联与导航保留为历史实现，不再跟进其专用问题。当前维护范围及已知限制以[维护说明](maintenance-policy.md)为准。

## 验证与复现

`verify-local.sh full` 运行两个 XCTest 目标及 Swift／Node／Python 检查；`portable` 不含 XCTest。构建脚本生成 arm64 macOS 应用并作 ad-hoc 严格签名检查，不安装、不接管日常运行数据。这些检查不替代真实桌面点击、全部宿主版本、长期恢复或 Intel 验收。

SuperChat 偶发不可见尚未确认根因，等待自然复现；诊断测试不能记为已修复回归。源码候选中是否纳入未跟踪诊断须看最终清单，不能套用含诊断工作区的历史测试计数。

独立评测或复现应固定源码、依赖、工具链、目标行为和预算，以状态正确性、配置所有权、异常保护、必要验证及报告准确性评价。使用合成数据，临时端点和注入路径；不要从相邻目录复制真实配置、运行库或认证文件。

正式 Lite 与开发 Local 使用独立的 Bundle ID、偏好域和数据目录，详见[身份与迁移说明](agent-integrations.md#从-local-迁移到-lite)。仅给已有 `.app` 改名不会改变编译身份。`AGENTPET_LITE_HOME`／`AGENTPET_LOCAL_HOME` 分别覆盖对应构建的 Core 运行根目录，不自动隔离 UserDefaults 或宿主数据；有效迁移后的 Lite 还会持有旧 Local 实例锁。并行 GUI 试验需要额外隔离偏好、端点与宿主配置，不能只改数据根目录。
