# AgentPet Lite 维护说明

AgentPet Lite 是个人维护的 macOS 衍生版。维护目标是日常使用中的任务状态、公开回复、会话导航、阅读回执与宠物体验；不承诺覆盖所有客户端版本、宿主或供应商。

## 接入范围

| 来源 | 承担的范围 |
| --- | --- |
| Codex | 已适配的 CLI／桌面与宿主组合，当前原生配置发现／移除检查使用 CLI 0.160.0；原生 Hook 的信任由用户完成 |
| Antigravity CLI（agy） | 已适配终端与宿主，当前 1.3.5 的配置、helper 和移除已检查；全新账号交互加载／真实模型链路未专项验收 |
| OpenCode | V1／V2 独立插件；V1 基线 1.18.34／1.19.0，V2 观察基线 2.0.29、TUI 导航最低 2.2.2（实测 2.2.2）；Install 前检测本机版本 |
| DSH | 应用维护协议消费端与连接检测；独立 `dsh-agentpet-bridge` 项目负责宿主适配、构建及预编译npm／tgz发行；安装更新交给DSH原生管理器，技术检查与真实宿主验收分别记录 |
| Pi | 持续维护原生扩展、Install／Remove 与任务生命周期；原生扩展基线 Pi 1.3.0；AionUI 专用组合只保留历史实现 |
| Agent Orchestrator（AO） | 本机项目聚合、精确成员导航及 Chat 阅读同步；后两项依赖带 `desktop-navigation.v1`／`session-read.v1` 的 AO 补丁版，当前验收基于官方 v0.14.6 加补丁；补丁兼容与发行由宿主维护方负责 |
| Claude Code | 仅保留部分适配和设置入口，不承担新增适配、版本兼容、故障修复或专项验收 |

AionUI／AionUI Team 专用适配已停止维护；不再新增适配、跟进版本、修复专用导航或安排专项验收。旧代码保留，Codex／agy／OpenCode／Pi 的通用接入继续维护。已退役的来源不重新启用，读取旧格式所需的共享迁移代码可继续保留。Codex／agy／OpenCode／Pi 的 Install／Remove 仅管理 AgentPet 的受识别全局注册；DSH 的桥接插件由其原生管理器管理，不能把“已配置”解释成客户端已加载、已信任或所有任务均可运行，详见[接入说明](agent-integrations.md)。

## DSH 插件维护归属

`@agentpet-lite/dsh-bridge` 的唯一活动实现位于独立 `dsh-agentpet-bridge` 项目，由 DSH 管理侧维护 SDK／UI 适配、测试和发行。AgentPet 主线只维护公开[协议契约](dsh-bridge-protocol.md)及消费端，不内附、构建或安装插件。toolkit 不纳入桥接依赖；旧AionUI Team监控桥与本插件分别管理。

插件版本与DSH版本仅作发行／宿主适配信息，应用按协议主版本、实际进程／Profile／Host、事件连接和能力确认接入。登记结构异常只作诊断，不按应用内附版本或摘要要求覆盖兼容插件。旧v1观察帧保持兼容；新的精确agy会话关联由桥接能力提供，应用不再读取其私有存储。

插件从已发布npm包或独立预编译tgz安装；本地候选尚未发布时不能按名称宣称可用。安装、更新、移除和宿主重启由用户在DSH原生管理器按授权完成；应用“Manage”只打开DSH。不同平台／版本、Client行为、长期恢复及自然任务气泡仍需实际证据，协议与构建检查不代替宿主验收。

## 数据与变更原则

保留现有用户偏好、宠物、养成、会话和阅读回执。页面移除不等于删除底层数据；应用替换不回灌旧运行状态。对客户端配置只修改明确属于 AgentPet 的条目，保留其他处理器、共享开关、原生权限和信任流程。

当前更新器停用、Updates 入口隐藏，不使用上游 feed。首版身份为 AgentPet Lite 1.0.0，使用 `io.github.jiziol.agentpet-lite` 与 `~/.agentpet-lite`；本地安装候选为 Apple Silicon DMG，使用 ad-hoc 签名、未公证。尚未公开发布或建立自动更新渠道；后续通过新版 DMG 或源码构建更新，具体以实际发布说明为准。

## 验证边界

隔离测试覆盖状态与配置变换，原生无模型检查验证客户端发现插件／Hook、helper 上报和移除后停止上报；它们不能代替全部真实业务场景。当前 OpenCode 完成气泡、Codex 10% 额度提醒与自然恢复提醒触发已有真实使用反馈通过，不扩大为所有宿主、额度阈值、持续时间和去重情况。

Pi 的运行／完成气泡和历史 AionUI 对应会话跳转曾获真实使用确认；这些历史反馈不代表 AionUI 继续维护。安装／更新／移除、自动续跑结束、退出上报、取消和错误另有针对性检查。人工输入／权限交互、团队并发及长期恢复仍需按具体宿主验收；独立终端定位的实现不等于所有终端会话跳转均已通过。

AO 项目汇总、主入口 leader／独立未读成员导航及 AO 内查看后的已读同步已有针对性使用确认；不扩大到 TUI、远程、Cloud 或所有 AO 版本。SuperChat 存在偶发不可见且根因未确认的已知问题，待下次自然复现后调查，不能记为已修复。

后续以真实日常反馈和具体复现定向修复。验证不向真实运行目录写合成事件，不替用户信任 Hook，也不额外消耗模型额度制造验收任务。已验证版本之外的故障需先确认客户端、宿主和配置差异。

## 隐私与安全

任务和公开回复会显示在桌面，截图、录屏和共享屏幕可能暴露内容。应用会读取已适配客户端的本机配置、会话元数据及必要的公开文本；“不额外调用模型”不等于“不读取任何对话”。请按使用环境控制可见范围。

| 路径 | 实际行为 |
| --- | --- |
| 默认宠物 | 从随包资源离线安装，不触发上游图库统计 |
| 手动在线图库 | 访问 `pets.thenightwatcher.online`、`agentpet.thenightwatcher.online` 及各素材下载地址；下载默认向后者 `/api/install` POST 宠物 slug，服务器也会看到正常网络请求信息 |
| Codex 额度 | 定时查询本机官方 CLI；不可用时可读取已有 Codex 登录信息向 `chatgpt.com/backend-api/wham/usage` 查询，携带所需认证及账号头；不创建模型任务 |
| 其他额度与更新代码 | 维护版 `AGENTPET_LOCAL` 不启动 Claude／OpenUsage 后台探测及 Sparkle 更新；保留实现不代表当前启用 |
| AO／DSH | 使用经身份校验的本机端点及发现文件；不代发模型任务、批准工具或重派会话 |
| Hook 注册 | 仅在用户操作 Install／Remove 时管理本项目可识别条目；备份可留在客户端配置目录 `.agentpet-backups`，不自动公开上传 |

当前没有项目自建云同步服务；在线图库、安装统计及提供商额度请求仍存在。不要将本机认证文件、Hook 备份、完整运行目录、日志或原始对话提交到 issue。报告问题前删除令牌、账号、个人路径及正文；公开回复也可能包含隐私。

发现安全问题时先以不含秘密的最小描述联系仓库维护者，请求私下传递复现材料；不要在公开 issue 粘贴有效凭据。仓库尚未提供经核实的专用安全邮箱，不虚构报告渠道。
