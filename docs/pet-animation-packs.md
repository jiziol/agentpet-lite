# 添加与划分宠物动画

本说明基于当前实际读取代码，供贡献者准备动画包。默认鲸鱼娘已实现33段媒体随包与离线首启；运行中的个人数据目录不作为分发资源。

## 包结构

```text
my-pet/
  pet.json
  spritesheet.webp
  animations.json
  edge-peek.png
  videos/
    idle-01.mov
  posters/
    idle-01.png
  LICENSE.assets
  SOURCE.md
```

当前加载器仍要求`pet.json`和可解码、有可见内容的精灵图；只有MOV目录尚不能独立加载。MOV目录是原精灵能力之外的可选动画扩展。素材文件／海报／精灵图各自须有明确来源，不能因其中一部分获许可就推定整个包都可再分发。

`pet.json`最小示例：

```json
{
  "id": "my-pet",
  "displayName": "我的宠物",
  "spritesheetPath": "spritesheet.webp"
}
```

id应稳定且避免与其他包冲突；后续更改id可能导致旧动画选择和按宠物保存的养成记录无法对应。description为可选展示字段。包内不放作者的等级、XP、成就、偏好、任务、账号或会话记录。

## 动画用途

| purposes值 | 设置中的分组 | 行为用途 |
| --- | --- | --- |
| idle | 空闲 | 无优先任务时的默认动作 |
| working | 工作 | 真实任务工作状态 |
| waiting | 等待 | 需要人工处理的任务 |
| success | 成功 | 完成反馈；不是基于文案猜测成功 |
| failure | 失败 | 失败反馈 |
| quota | 额度提醒 | 当前已接入的额度提醒动画 |
| levelup | 升级 | 本地养成升级动作 |
| tap | 点击 | 点击宠物反馈 |
| drag | 拖拽 | 拖拽宠物反馈；单次播放，持续拖动保持末帧 |

`drag`片段按实际拖动阈值触发，从第一帧单次播放；持续拖动超过片长时保持末帧，松手后立即按最新任务状态恢复，不循环重播。

可选的`edge-peek.png`放在包根目录（与`pet.json`同级），是贴边收起的静态探头图。应用只读取包内文件，按非透明内容裁边后贴在屏幕外侧边缘；左侧贴边水平镜像。缺少该文件、解码失败或没有有效不透明内容时，使用应用内置的默认贴边静图；拖出后恢复所选宠物自身的动作。默认贴片只用于贴边展示，不加入该宠物的九组动画，也不写入宠物目录。不依赖Downloads或网络；若应用内置贴片也不可用，则保持普通宠物可见、可拖拽。

这九组均可多选；一个片段可归入多个用途，数组最多9项。已存在的done／celebrate／sleepy属于兼容用途，不作为新增贡献包的主要分组，已有绑定中的done／celebrate会迁移到success；新MOV条目的purposes应直接写success，不能指望仅写done／celebrate就自动进入成功候选组。不能随意增加用途名而不修改加载器／选择／调度逻辑。

一组选择一个时固定使用该片段，选择多个时每次触发随机选取；不表示一个触发会把整组顺序播完。成功／失败的未读持续、点击反馈时长、优先级等由应用调度处理，目录分类不会改变任务语义。

`animations.json`示例（名称与时长须替换为实际媒体信息）：

```json
{
  "version": 1,
  "clips": [
    {
      "id": "my-pet-idle-01",
      "name": "idle-01",
      "displayName": "空闲动作一",
      "category": "空闲",
      "file": "videos/idle-01.mov",
      "poster": "posters/idle-01.png",
      "duration": 5.0,
      "width": 640,
      "height": 360,
      "purposes": ["idle"]
    }
  ]
}
```

- 当前目录版本为1，最多512个片段，清单不超过1MiB；id必须唯一，不能以保留前缀`sheet:`开头。
- id／name最长200字符，category最长100字符；displayName若提供须为1–200字符。
- 时长必须为有限正数、不超过600秒；宽高为1–4096；单条视频为1字节至256MiB。必须为单视频轨的 HEVC with Alpha `.mov`，加载与导入均核对实际编码、alpha通道、解码后的透明像素及可见内容，并完整解码。单条解码上限为36000帧、累计20亿像素和30秒处理时间，超限明确拒绝。600秒是资源上限，不是建议时长；5—10秒也不是九组的统一要求。
- file和poster都必须存在并位于包内。拒绝绝对路径、父目录穿越和逃出包目录的符号链接。海报提供可解码图像；不要只创建同名空文件。
- 条目逐条解码与校验；字段、媒体、路径、重复ID或海报无效只跳过该条，并在动画设置中报告。重复ID保留第一条有效项。整体清单的版本、大小、数量或JSON无效时使用该宠物自身的原生回退；原生精灵图也无效则拒绝加载，并在选择宠物处报告。sha256可用于来源记录，但不是运行时完整性保证。

当前`创建宠物`入口用于精灵图；完整MOV包的自动导入尚未单独实现。现阶段完整包放在本地数据根目录的`pets/<id>/`，重新加载／选择后识别；Local构建数据根为`~/.agentpet-local`。不要覆盖已存在的同id用户包。后续可在既有导入边界内改进，不必改动气泡页。

## 在设置中导入单条动画

“动画”的九组均支持从 Finder 拖入一个或多个 MOV，或在当前组空白处右键 **Add** 后多选。逐文件处理：成功项立即显示，可悬停预览、选择并播放，失败项逐条显示原因；导入不自动更改已有播放选择。原精灵图片段与视频共存。没有明确用途映射的宠物默认复用它自己的首个原生动作，不按精灵图行号假定用途；已有有效选择保留。

导入使用上述同一套媒体限制，在后台验证、复制和生成透明PNG海报；不自动转码。请从有透明背景的源工程导出 QuickTime MOV，编码选 **HEVC with Alpha** 并保留Alpha。普通HEVC、H.264或修改文件扩展名无法获得透明通道；把不透明视频转码也不会还原透明背景。

素材副本和海报保存在当前数据域的 `pets/<pet-id>/animation-imports/<uuid>/`，原文件不会删除或覆盖，移走原文件不影响使用。用户侧 `animation-library.json` 版本1分别保存素材稳定身份（`import:<uuid>`）和九组的素材ID引用。原生 `animations.json` 保持不变；原精灵图ID保持 `sheet:<index>`。播放选择继续使用按宠物隔离的v2偏好键，名称和养成无需迁移。组引用可共享同一素材；组关系与文件所有权各自保存，不能靠删除原生文件实现组内管理。

## 按组移除动画

卡片右键 **Remove** 可单项移除；当前组空白处右键 **Remove** 进入批量移除模式。每次进入为空选，红色勾选仅表示待移除项，不改变正常蓝色播放选择。只在该模式显示右下角垃圾桶，空选禁用；可取消，切组自动退出并清空。单项与批量都在确认后执行，取消不改分组、文件或绑定。

每组至少保留一个有效的该宠物原生动作，包括原精灵片段或宠物包自带视频；自定义导入项不能替代最低原生保障。无用途映射的外部宠物可让九组共用一个自身原生默认。批量删除按最终结果整体校验，不静默跳过受保护项。比如“拖拽”保留有效原生拖拽视频时，可以批量移除该组其他旧精灵片段。

移除只影响当前宠物的当前组。原生项通过用户侧分组记录隐藏，不改精灵图或内置媒体；其他组引用继续有效。应用自管导入文件仅在没有其他有效分组、播放或同路径媒体引用时清理，保留用户原文件。移除当前播放选择后改用有效保留项或原生回退；原子写入组关系后，即使偏好尚未来得及更新就退出，重启也会过滤旧的失效选择，不自动把已移除项加入分组。

宠物页保留名称/等级/描述展示与选择、浏览、创建及动画入口，既有自定义名称仍保留。开启按项目分宠物时，使用“宠物配置”选择默认或项目，继续支持添加项目、选择绑定及移除项目。图库提示可关闭并记住关闭状态，不需要额外确认。

## 默认鲸鱼娘的打包边界

已筛选素材共33段：空闲9、工作4、等待4、成功5、失败2、额度2、升级3、点击3、拖拽1。默认方案使用此已筛选集合；不恢复106段完整素材或暗夜图标实验。打包必须采用明确资源清单，不能整树复制用户数据目录或备份目录。

新用户获得默认媒体，养成状态由应用从初始值创建；已有用户的养成、动画选择、宠物名称和偏好继续保留，不因默认包增加而重置。默认包没有纳入来源待核的旧spritesheet.webp，直接使用已核同源的悠闲哼歌海报作为完整单帧回退。

鲸鱼娘来源为[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。固定来源版本[e4c8c2a README许可说明](https://github.com/PC2005-cloud/dsh-pet/blob/e4c8c2af8b8b982d199d39fdec9de3ed5f84ecc5/README.md#许可)区分代码与素材：代码MIT；动画／提示词／源视频用于开源项目时需遵守其非商业条件，并在介绍、展示、分发衍生作品的位置附原项目链接。此素材条件与本项目源码MIT分别说明，About、README及未来发布页都要保留来源链接。所有贡献者添加自己的素材时，同样需提供独立的许可与署名信息。

## 完整单帧回退与离线首启

pet.json可增加可选字段spritesheetLayout，值为single，spritesheetPath指向完整单帧海报。该模式保留整张图里的分离发饰和透明边距，不按透明行列切成小网格；字段缺省时沿用既有网格切分。默认包的回退海报为160×90，MOV为640×360，两者比例一致，原始文件不改写。

资源目录：Sources/App/Resources/DefaultPets/deepseek。SwiftPM按目录复制；build-local.sh仅将DefaultPets资源根放入应用内资源bundle，不复制缓存里可能残留的旧捐赠资源。已打包.app直接从自己的Contents/Resources定位资源，不依赖开发机构建缓存。

首启安装器在ImagePetStore.loadFast前运行；已有选择／非空宠物目录保持，旧网络下载尝试标记不阻止本次离线安装。新安装用隐藏stage复制／校验后同盘move，失败不消耗首启标记，现有目的地不替换；用户删除已安装默认宠物后，不在每次启动重新添加。用户数据、绑定、名称和养成仍各自保存在原用户域。

删除模式支持鼠标拖框选择和 Shift＋点击连续范围，Shift＋拖框可追加选择。切组或取消清空删除选择；这些操作不改变普通播放选择，移除仍须二次确认。

原生清单已为某用途明确指定视频时，该组候选沿用这份用途清单，不额外加入全部旧精灵行。已有有效播放选择仍保留；用户侧显式组记录优先，不自动增删。没有专用原生映射的用途仍可使用该宠物自身精灵回退，首次导入自定义MOV不会隐藏原精灵动作。

The offline factory pet is deepseek酱: 33 selected native clips with the configured nine purposes and within-group order. New users receive this multi-selection preset at Lv 0; no XP, care or runtime preference files are shipped. Existing installations are preserved.
